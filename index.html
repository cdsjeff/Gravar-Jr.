Gravar Jr. Help

v1.39

Folder menu. Use 📁 to choose a video, load or save a project, create Auto Lines, open Starting Up, open Help, and export CSV or HTML.

Video loading. Choose Local file, YouTube, Panopto, or a named saved streaming link from Choose Video. The included test link is Lone Ranger-AAC practitioner. Use Add Streaming Link in the folder menu to add more YouTube or Panopto links to the selectable list. Local files provide the most complete browser control. YouTube and institutional embeds may restrict frame capture or direct time control depending on browser and source permissions.

Transport and video manipulation. Use the side controls for ±5 seconds, ±1 second, and Play/Pause. Command-click/Ctrl-click the ±1 second arrows for ±0.1 second. Hold the ±1 second arrows to step at about 7 frames per second. Command-Option drag left/right on the video to scrub forward/backward. Command-Option drag up/down, pinch, or the video +/− buttons zoom the video picture only. The black pane and the original visible picture rectangle stay fixed. The enlarged picture is clipped inside that original picture rectangle. Plain click-drag repositions the enlarged picture within that same boundary.

Transcript lines. Use Start and End to copy the current video time into the selected line. Click or 0.5-second touch-hold the line-number/check area to seek to that line's Start. Double-click/tap the Start/check area to show editable Start fields for all lines. Double-click/tap the End/check area to show editable End fields for all lines. Double-click/tap a visible timecode field to hide that group.

Line playback. Double-click/double-tap a transcript line, or Command-click/Ctrl-click the line, to play the video from that line's Start to End.

Notes. The ▣ button opens and closes a line-specific note directly below the transcript line. The ◇ Field Note button opens a project-wide rich-text note. Field Note supports bold, italic, color dots, clear formatting, table insertion, table row/column editing, and RTF export.

Frame clips. Fr Clip inserts the currently visible portion of the video picture and timing information into the Field Note. If the picture is zoomed and panned, the frame clip captures only that visible cropped area, not the full source frame. Local videos can usually export the visible frame image. YouTube/iframe sources may export timing only if the browser blocks direct image capture.

Exports. CSV and HTML exports include transcript lines, timing, line notes, field notes, and frame-clip material where available. Project JSON preserves the working project state.

Starting Up Gravar Jr.

v1.39

1. Open the app. For iPad or Chromebook use the hosted version or the package folder on a web server. On a Mac, the standalone HTML can be opened directly for local testing.

2. Choose a video. Open 📁 and choose Local file, YouTube, Panopto, or a named streaming link such as Lone Ranger-AAC practitioner. Use Add Streaming Link to add more YouTube or Panopto links to the menu. Local file is best for class demos that need frame capture and full time control.

3. Create transcript rows. Add rows manually with Add, or use Auto Line from the folder menu to generate lines at a fixed interval, such as 10 seconds.

4. Mark times. Select a line, move the video to the onset, press Start; move to the offset, press End. Double-click/tap the timing check areas to display editable timecodes.

5. Write observations. Type in the transcript line, add a line-specific note with ▣, and add project-wide observations in ◇ Field Note. Use Fr Clip to place the visible cropped video picture and timecode in the Field Note.

6. Save and export. Save the working project as JSON. Export CSV for data review or HTML for a readable report with notes and frame clips.
