Gravar Jr. Help — v1.43

Startup screen

The opening video pane displays a compact startup guide until a video is loaded. The last line identifies the current file: Gravar_Jr_v1.43_streaming_links.html.

Choosing videos

Open the folder menu and use Choose Video to select a local file, paste a YouTube link, paste a Panopto embed link, or choose a saved streaming link.

Built-in streaming links are Lone Ranger-AAC practitioner, Bill and Daughter, Bill and Louise Gesture, Dean & Linda (short), and Jimmy & Tammy. Use Add Streaming Link to add more named YouTube or Panopto links to the Choose Video menu.

Shortcuts / Clicks

Open 📁 and choose Shortcuts / Clicks at the bottom of the menu to review keyboard shortcuts, click combinations, double-click/tap actions, and touch gestures.

Transcript rows and timing

Use Add to create rows or Auto Line from the folder menu to create fixed-interval rows. Use Start and End to mark timing. Double-click/tap timing check areas to display editable timecodes. Double-click/double-tap or Command/Ctrl-click a transcript line to play from line onset to offset.

Notes and frame clips

Use ▣ for a line-specific note and ◇ Field Note for project-wide observations. Fr Clip inserts the currently visible cropped portion of the local video picture into the Field Note with timing information.

Saving and export

Save JSON for working projects. Export CSV for data review or HTML for a readable report with notes and frame clips.
