Gravar Jr. Help — v1.39

Choosing videos

Open the folder menu and use Choose Video to select a local file, paste a YouTube link, paste a Panopto embed link, or choose a saved streaming link.

The built-in test streaming link is Lone Ranger-AAC practitioner. Use Add Streaming Link to add more named YouTube or Panopto links to the Choose Video menu. Added links are saved in the browser’s local storage on that device/browser.

Streaming limits

YouTube and Panopto links depend on the source permitting embedded playback. YouTube usually requires Gravar Jr. to be opened from an HTTPS/localhost web origin rather than directly from a downloaded file. Panopto links should usually be institution-provided embed links.

Frame clips

Fr Clip inserts the currently visible cropped portion of the local video picture into the Field Note with timing information. Some streaming sources may allow timing only because browser security can block image capture.

Transcript rows

Use Start and End to mark timing. Double-click or Command/Ctrl-click a transcript line to play from the line onset to offset. Use Auto Line from the folder menu to create timed rows across the loaded video.
