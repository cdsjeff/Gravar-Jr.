Gravar Jr. Help — v1.49

Choosing videos

Open the folder menu and use Choose Video for a local file, YouTube, Panopto, or a named streaming link. Built-in links include Lone Ranger-AAC practitioner, Bill and Daughter, Bill and Louise Gesture, Jimmy & Tammy, and Dean & Linda (short).

Streaming-link management

Use Add Streaming Link to add a named YouTube or Panopto link. Use Delete Streaming Link to remove a link from the menu on the current browser/device. Deleting a built-in link hides it locally; Restore Built-in Links restores built-ins. Deleting a user-added link removes it from local storage.

Transcript rows and Auto Line

Use Add for individual rows. Auto Line adds fixed-interval rows without deleting existing transcript lines. Check Auto-sort Start to keep lines in chronological Start-time order as Start values are set or edited. Uncheck it to preserve the current manual order.

Line playback

Double-click/double-tap a transcript line, or Command-click/Ctrl-click the line, to play from Start to End. The current build keeps the row in place after the first click and includes an explicit touch/pen double-tap fallback. If a row has no End, playback stops at the earliest later Start time.

Local MP4 playback

Gravar Jr. v1.49 repairs local MP4 display. Standard H.264/AAC MP4 files use the local canvas display when available and automatically fall back to the browser's native video element if canvas drawing is unavailable. This prevents the RGB adjustment system from blanking otherwise valid video.

Video picture adjustments

Click ☼ beside the video zoom controls. Adjust Brightness, Contrast, Color (saturation), plus independent Red, Green, and Blue channels. Brightness, Contrast, and Color now extend to 300%; RGB channels range from 0% to 300%. Reset returns all six controls to 100%. These controls change only the displayed picture. Settings are saved with the project. For capturable local video, Fr Clip records the adjusted appearance.

Timing

Use Start and End to mark a selected line. Double-click/tap the timing check areas to display editable timecodes.

Notes and frame clips

Use ▣ for a line-specific note and ◇ Field Note for project-wide observations. Fr Clip inserts the visible cropped local-video picture and timing information into the Field Note.

Saving and export

Save JSON for working projects. Export CSV for data review or HTML for a readable report with notes and frame clips.
