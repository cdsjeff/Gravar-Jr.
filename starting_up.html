Starting Up Gravar Jr. — v1.49

  • Open 📁 and choose Local file…, YouTube, Panopto, or a named streaming link.
  • Use Add Streaming Link to add a named YouTube or Panopto link. Use Delete Streaming Link to remove links from the menu on this device.
  • Use Add to add individual transcript rows. Auto Line adds fixed-interval rows and preserves every existing line.
  • Check Auto-sort Start if you want lines automatically reordered by Start time whenever Start values change.
  • Move the video to the onset, select a line, and click Start; move to the offset and click End.
  • Double-click/tap timing check areas to display editable Start or End timecodes.
  • Double-click/double-tap a transcript line to play that line from Start to End.
  • Click ☼ beside the video zoom controls to adjust Brightness, Contrast, Color, and the Red/Green/Blue channels. Maximum adjustment is 300%; Reset returns every control to 100%.
  • Type in the transcript line, use ▣ for a line note, and use ◇ Field Note for project-wide observations.
  • Use Fr Clip to place the visible cropped and adjusted local-video picture and timecode in the Field Note.
  • Save the working project as JSON. Export CSV for data review or HTML for a readable report.
  • For more features, open 📁 and choose Starting Up, Help, or Shortcuts / Clicks. File: Gravar_Jr_v1.49.html
