Starting Up Gravar Jr. — v1.39

  1. Open index.html from a hosted web location, such as GitHub Pages, for the best streaming-video behavior.
  2. Open the folder menu and choose Local file, YouTube, Panopto, or a named streaming link.
  3. The included saved streaming link is Lone Ranger-AAC practitioner.
  4. To add another class video, choose Add Streaming Link, give it a name, paste the YouTube or Panopto link, and then choose it later from Choose Video.
  5. Create transcript rows manually with Add, or use Auto Line to create rows at a fixed interval.
  6. Use Field Note for project-wide notes and Fr Clip to add the currently visible local-video frame to the Field Note.
  7. Save your work with Save Project, and export with Export CSV or Export HTML.
