Starting Up Gravar Jr.

v1.38 — Visible Frame Clip

1. Open Gravar Jr.

Open index.html from the package or deploy the package to a web host for iPad/YouTube use.

2. Choose a video

Open the folder menu and choose Local file, YouTube, or Panopto. Local file is best when you need visible frame capture and full timing control.

3. Navigate the picture

Use +/− or pinch to enlarge the picture inside its original picture boundary. The black video pane and original picture boundary should not expand. Drag the enlarged picture to reposition it. Use Command-Option drag left/right to scrub and Command-Option drag up/down to zoom.

4. Add transcript lines

Use Add, Start, and End. Use Auto Line from the folder menu to create timed blank lines at a specified interval.

5. Add notes and clips

Use ▣ for a line note. Use ◇ Field Note for field observations and Fr Clip to insert a frame and timing information into the Field Note.

6. Save and export

Save the project JSON to preserve the working project. Export CSV for tabular review or HTML for a readable report with notes and frame clips.
