Starting Up Gravar Jr. — v1.43

  • Open 📁 and choose Local file, YouTube, Panopto, or a named streaming link.
  • Use Add to add transcript rows, or use Auto Line in the folder menu for fixed-interval lines.
  • To mark Start and End, move the video to the desired point, select the line, then click Start or End.
  • Double-click/tap timing check areas to display editable timecodes.
  • Type in the transcript line, add a line-specific note with ▣, and add project-wide observations in ◇ Field Note.
  • Use Fr Clip to place the visible cropped video picture and timecode in the Field Note.
  • Save the working project as JSON. Export CSV for data review or HTML for a readable report with notes and frame clips.
  • To find out about more features, open 📁 and choose Starting Up, Help, or Shortcuts / Clicks. File: Gravar_Jr_v1.43_streaming_links.html
